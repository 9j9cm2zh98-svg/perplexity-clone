# Perplexity Clone

A modern **AI-powered search engine** inspired by Perplexity, built with **TanStack Start, React, TypeScript, and Tailwind CSS**.

This project combines a clean conversational interface with AI-powered search to provide concise, context-aware answers to user queries. It was developed as a hands-on project to explore modern full-stack development, AI integration, web search, and streaming responses.

## ✨ Features

* 🤖 AI-powered conversational search
* 🔎 Web-based search and information retrieval
* 💬 Chat-style interface
* ⚡ Fast and responsive UI
* 📡 Streaming AI responses
* 🎨 Modern responsive design
* 🧩 Full-stack architecture with TanStack Start
* 🌐 Real-time interaction with search and AI services

## 🚀 Getting Started

### Clone the repository

```sh
git clone <this-repository-url>
cd <repository-name>
```

### Install dependencies

```sh
npm i
```

### Start the development server

```sh
npm run dev
```

The application will then be available at the local development URL shown in your terminal.

## 🛠️ Built With

* **TanStack Start** — Full-stack React framework
* **TypeScript** — Type-safe development
* **React** — User interface
* **Tailwind CSS** — Styling and responsive design

## 📌 Project Purpose

This project was created to gain practical experience in building **AI-powered full-stack applications**, including frontend development, API integration, search functionality, and AI-driven conversational experiences.
